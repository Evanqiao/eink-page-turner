# E-Ink Page Turner

专为安卓墨水屏设备优化的 Obsidian 阅读翻页插件。阅读模式下点击屏幕左侧向上翻页、点击右侧向下翻页，针对墨水屏刷新特性优化体验。

## 功能

- **点击翻页** — 点击屏幕左侧区域向上翻页，右侧区域向下翻页，中间区域保留默认行为
- **防误触** — 自动区分点击与滑动，点击链接、按钮等可交互元素时不触发翻页
- **墨水屏优化** — 禁用平滑滚动和动画效果，消除残影
- **翻页重叠** — 可配置翻页时的内容重叠像素，避免内容断裂
- **记住阅读位置** — 自动记录每篇笔记滚动到的位置，重新打开时恢复；位置文件可随 Obsidian Sync 等方案多端同步
- **全屏支持** — 全屏模式下可选择启用编辑模式翻页

## 安装

### 手动安装

1. 下载 `main.js`、`manifest.json`、`styles.css`
2. 在 Obsidian vault 中创建目录 `.obsidian/plugins/eink-page-turner/`
3. 将三个文件复制到该目录
4. 在 Obsidian 设置中启用插件

### 通过 BRAT 安装

1. 在 Obsidian 社区插件库中搜索 **BRAT** 并启用
2. 打开 BRAT 设置，点击 **Add Beta plugin**
3. 输入仓库地址：`Evanqiao/eink-page-turner`
4. BRAT 会自动下载插件文件并在 Obsidian 中启用

> 每次打开 Obsidian 时 BRAT 会自动检查更新。

## 设置

插件提供以下可配置项：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 启用插件 | 关闭 | 点击翻页的总开关 |
| 记住阅读位置 | 开启 | 记录并在打开笔记时恢复阅读位置（独立于点击翻页开关） |
| 位置文件路径 | `EinkPageTurner/positions.json` | 位置数据文件在库内的相对路径 |
| 左侧点击区域比例 | 25% | 屏幕左侧触发向上翻页的区域 |
| 右侧点击区域比例 | 25% | 屏幕右侧触发向下翻页的区域 |
| 翻页重叠像素 | 50px | 翻页时保留上一页内容的像素量 |
| 编辑模式翻页 | 关闭 | 开启后编辑模式也可使用点击翻页 |

## 同步阅读位置

阅读位置保存在库内的 JSON 文件（默认 `EinkPageTurner/positions.json`）中，因此**只要该文件被同步，多端位置就自动同步**，不需要插件自己做网络通信。Obsidian Sync、Syncthing、iCloud、Git 等任何同步库文件的方式都可以。

实现上有几个考虑：

- **按笔记合并，而不是整份覆盖**：每次写入前都会重新读取文件，按每篇笔记的时间戳取较新的记录再写回，所以两台设备先后阅读不同笔记不会互相冲掉。同一篇笔记在两台设备上同时阅读时，以较晚的位置为准。
- **比例 + 文本锚点**：位置同时记录滚动比例和可视区顶部段落的文本。换设备时即使字体大小、屏幕宽度不同，也能尽量回到同一段内容；锚点匹配不到时自动退回按比例恢复。
- **只对阅读模式生效**：恢复和记录都只在 Markdown 阅读视图进行，不会干扰编辑光标。
- **隐藏文件夹不同步**：Obsidian Sync 不会同步以 `.` 开头的隐藏文件夹，所以默认使用普通文件夹 `EinkPageTurner/`；如果你把该文件加入「排除的文件」，它就不会被同步。
- **极端情况下可能有冲突副本**：如果两端几乎同时写入这个文件，同步服务可能生成 `positions.sync-conflict-….json` 之类的副本，插件只读取固定路径，不会读取副本；正常阅读场景下几乎不会发生。
- **不要手改位置文件**：文件损坏时插件会跳过写入以免覆盖数据，但格式错误会导致位置暂时无法记录。
